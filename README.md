## 👋 关于我

我是樊烨，一名专注 **Agent 工作流** 的 AI 产品经理。

我的判断是：Agent 的价值不在"能调用多少工具"，而在**能不能把一个岗位的真实工作流拆开、沉淀成可复用、可治理的 Skill**。会用 RAG、会接 MCP 只能证明能干活；能说清"哪一步该交给 AI、哪一步必须人来拍板"，才是产品经理的活。

所以我在做的事，是先拿自己开刀：用 DeepSeek Harness 搭一个**个人 AI 产品经理工作台**，把立项、PRD、原型、评测、上线复盘逐个做成 Skill，每一步都留出 human in the loop 的确认点。

## 🔭 我正在研究

> 每周更新 · 最近更新：2026-10-19
